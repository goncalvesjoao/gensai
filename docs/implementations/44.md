## Decisions and tradeoffs

Use the existing browser rendered-behavior and built-document pre-paint testing boundaries approved in the spec. Preserve official hazard colours and the pale basemap per `docs/adr/0001-official-hazard-sources.md`.

The synchronous layout initializer records selected mode in `data-theme-mode` separately from resolved `data-theme`. Hydration consumes that result. The existing storage key retains explicit Light/Dark compatibility and now accepts System. Earlier browser scenarios deliberately select their intended appearance instead of assuming one activation selects Dark.

A mode-scoped media-query listener updates only System appearance. Its functional state update preserves the selected mode and language and uses no storage access. Entering System resolves the current device appearance immediately, including changes made during explicit modes.

Review fixes share theme selection through `tests/browser/helpers.mjs`, bounding attempts to one complete cycle and asserting the result. Existing zoom tests now wait up to ten seconds for the visible scale to change rather than sampling after a fixed 500 ms delay; their original zoom assertions remain.
