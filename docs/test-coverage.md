# Test execution and coverage

`npm test` builds once, runs the top-level Node tests, then runs every local
browser test file against managed preview. Production-host verification is
separate. Live Photon and official hazard probes run only with `npm run test:live`.

Browser setup shares one Chromium process per file. Each page owns a fresh
context so cookies, storage, permissions and request overrides cannot leak.
Sessions close their contexts in the existing `finally` blocks; the file's
`after` hook closes Chromium. The setup regression checks process sharing,
cookie isolation, context closure and survival of a separate session.

Local provider requests use fixture responses by default. Page-level overrides
retain precedence for scenario-specific delays, failures, colours and results.
The live command selects only the two live probes and enables their providers.
The production command still checks real HTTPS document routing and navigation;
fixture map tiles do not establish live hazard availability.

Production logic was not extracted solely to create faster tests. Exhaustive
geography already has a useful Node interface; focus, React event coordination,
layout and rendered pixels still require a browser. The remaining speed changes
remove repeated scenarios rather than replace integration evidence with helper tests.
